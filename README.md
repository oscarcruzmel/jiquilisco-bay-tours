# Jiquilisco Bay Tours

Source repository for the bilingual Jiquilisco Bay Tours websites.

- `jiquiliscobay.com` — English
- `bahiajiquilisco.com` — Spanish

## Update workflow

Edit this repository on the `main` branch. Once Cloudflare Pages is connected, each push to `main` will automatically deploy the latest site version.

## Migration status

The live `.com` domains remain on their current hosting until the replacement site is reviewed and the Cloudflare Pages deployment is verified. Do not change production DNS before validation.
